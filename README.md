# iPhone 17 Pro Status Bar Calibration

This package captures three pilot screenshots from Apple's official iPhone 17
Pro Simulator. It does not modify the existing screenshot generator.

Pilot pairs:

- 01:33, battery 50
- 13:03, battery 73
- 23:26, battery 95

The probe app uses a solid `#ededed` background and asks iOS for dark status bar
content. The workflow keeps the full simulator screenshots and diagnostic logs
in one downloadable artifact.

Do not build the complete time and battery material pool until these samples
have been compared with physical iPhone 17 Pro reference screenshots.
